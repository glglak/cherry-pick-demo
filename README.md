# Git Cherry-Pick Demonstration

This repository demonstrates the concept of cherry-picking in Git with a practical example.

## What is Cherry-Picking?

Cherry-picking in Git means applying the changes from a specific commit from one branch to another. It's like selecting a single "cherry" (commit) from a tree (branch) and applying it elsewhere.

## When to Use Cherry-Pick

- When you want to apply a specific bug fix to multiple branches
- When you need to backport features to maintenance versions
- When you want to salvage work from an abandoned feature branch
- When you need to apply changes to the main branch without merging an entire feature branch

## Benefits of Cherry-Picking

- Selective application of changes
- Maintaining clean branch history
- Applying fixes across multiple release branches
- Recovering partial work from branches with mixed changes
